# Точка входа для агента

Это репозиторий команды на хакатоне AI Challenge 2026, задача A «Цифровой детектив: поймай
генеративку» (сегментация ИИ-манипуляций на изображениях). Прежде чем что-либо делать:

1. Прочитай **[HACKATHON.md](HACKATHON.md)** — полное условие, метрика AIC Score, данные,
   ограничения (100 GFLOPs, 50 ms, запрет теста в обучении, только выданные данные), формат сдачи,
   критерии оценки, инфраструктура.
2. Прочитай **[TEAM.md](TEAM.md)** — как мы работаем вдвоём: общий кластер, общие папки, общее
   окружение, git-процесс, правила по GPU, где лежат данные и запуски.
3. Прочитай **[DECISIONS.md](DECISIONS.md)** — журнал всех договорённостей команды (D-xx). Любое
   новое решение, принятое в чате с человеком, добавляй туда же записью с датой.
4. Прочитай **[VALIDATION.md](VALIDATION.md)** — спецификация валидации (метрика, split, пулы
   негативов, порог, калибровка по лидерборду). Не менять на месте: любое изменение = новая версия.
5. Никогда не коммить данные, чекпоинты, пароли. `.gitignore` уже это отражает.
6. Все пути к данным — только через переменную окружения `AIC_DATA_DIR` (см. TEAM.md).

Язык общения и документации — русский. Комментарии в коде — русские или английские, но единообразно в файле.
